MLOps Cancer Prediction Pipeline

End-to-End Reproducibility, DVC Versioning & CI/CD

🏆 0.916 ROC-AUC High-Accuracy Classification Pipeline

An enterprise-grade, reproducible machine learning engineering pipeline implementing DVC for dataset and stage versioning, MLflow for experiment tracking, and containerized FastAPI deployment with automated GitHub Actions testing.

1 / 3

What it does

  • Engineered an end-to-end reproducible ML pipeline covering data preprocessing, feature engineering, multi-model training, and production serving.
  • Achieved a verified 0.916 ROC-AUC score utilizing an optimized Random Forest classification architecture with rigorous cross-validation and hyperparameter tuning.
  • Integrated Data Version Control (DVC) to version dataset splits, feature transformations, and model weights, eliminating data drift and enabling full workflow reproducibility.
  • Conducted systematic experiment tracking with MLflow, logging parameters, metrics (precision, recall, F1, ROC-AUC), and model artifacts across iterative training runs.
  • Containerized the inference service with Docker and built a high-throughput FastAPI endpoint with sub-15ms prediction latency and pydantic schema validation.
  • Constructed a continuous integration and delivery pipeline with GitHub Actions running automated unit tests, model performance threshold assertions, and lint checks.

Built with

Python · Scikit-learn · MLflow · DVC · Docker · FastAPI · GitHub Actions CI/CD · Pytest · Linux

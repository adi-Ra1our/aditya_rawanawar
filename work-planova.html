Planova — AI Project Workspace

Collaborative Task Management & Conversational AI

🤖 Conversational Project Intelligence Engine

A full-stack collaborative workspace platform built with React, Node.js, Express, and MongoDB, combining granular role-based access control with an embedded AI assistant to answer task queries and automate project deadlines.

1 / 3

What it does

  • Architected a full-stack collaborative project management platform featuring kanban sprint boards, custom task lifecycles, and priority queues.
  • Implemented secure role-based access control (RBAC) using JWT and bcrypt, ensuring strict privilege boundaries between project managers, contributors, and guests.
  • Integrated an intelligent conversational AI assistant chatbot capable of querying project context, retrieving active deliverables, and providing natural language project summaries.
  • Built automated background deadline reminder pipelines to alert assignees via real-time notifications ahead of target milestones.
  • Designed normalized MongoDB document schemas optimized for fast querying across multi-project organizations with zero document bloat.
  • Crafted a responsive, intuitive React.js frontend interface with state management handling live task movement and instant filter updates.

Built with

React.js · Node.js · Express.js · MongoDB · Mongoose · JWT · AI Chatbot · REST APIs

# Aditya B Rawanawar — Personal Portfolio & Interactive Desk

A neo-brutalist developer portfolio and spatial 2D interactive canvas built for **Aditya B Rawanawar** — Artificial Intelligence & Machine Learning Engineer.

![Portfolio Banner](assets/pfp/aditya.jpg)

## ⚡ Highlights

- **Neo-Brutalist Design System:** 2px high-contrast borders, tactile offset drop shadows, customizable themes (Cream, Tokyo Night, Dracula, Nord, Cyber).
- **Interactive 2D Spatial Desk (`canvas.html`):** An infinite draggable desktop environment with macOS-style dock, tactile sound effects, and an interactive AI Systems Quiz mini-game.
- **Scroll-Spy Role Navigation:** Sticky sidebar index tracking real-time reading progress through internships and education.
- **Full Case Studies:** Interactive 3-slide visual architecture carousels covering production Agentic AI, MLOps, and full-stack projects.
- **Zero-Dependency Architecture:** Pure modern HTML5, CSS3, and JavaScript — blazingly fast with 100/100 Lighthouse performance and instant static hosting.

## 🛠 Tech Stack

- **Design & Layout:** Custom CSS custom properties, CSS Grid, Flexbox, Space Grotesk, JetBrains Mono
- **Interactivity:** Vanilla ES6+, Web Audio API (acoustic tactile clicks without external audio files), IntersectionObserver API
- **Deployment:** GitHub Pages / Vercel / Netlify

## 🚀 Local Development

Clone the repository and start any local static server:

```bash
# Python
python -m http.server 3000

# or Node.js npx
npx serve .
```

Then open `http://localhost:3000` in your browser.

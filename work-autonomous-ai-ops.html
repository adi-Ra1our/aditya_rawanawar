⚡ Real-Time Edge Telemetry & Local LLM Decision Engine

A distributed AIOps telemetry and anomaly detection platform utilizing TF-IDF log vectorization, Isolation Forest models, and metric risk scoring to detect infrastructure instability in real time — paired with local Ollama Mistral incident explanations and ESP32 edge alerts.

1 / 3

What it does

  • Built a real-time AIOps telemetry and anomaly detection platform fusing low-level machine logs and sensor metrics to catch infrastructure instability before failure occurs.
  • Employed TF-IDF log vectorization to convert unstructured server and syslog streams into dense feature representations, capturing abnormal token frequency shifts.
  • Trained and deployed Isolation Forest models to calculate dynamic metric risk scores, detecting multivariate anomalies without manual threshold calibration.
  • Integrated a fusion intelligence decision engine that aggregates anomaly scores across CPU, memory, packet jitter, and hardware vibration sensors.
  • Implemented local LLM incident explanations via Ollama (Mistral 7B), generating human-readable root-cause analyses and remediation steps with zero cloud latency and full data privacy.
  • Engineered physical ESP32 edge hardware alerts with instant LED/buzzer triggers for on-site facility engineers, alongside a live React observability dashboard.

Built with

Python · FastAPI · Scikit-learn · Ollama (Mistral) · React · ESP32 · FreeRTOS · WebSockets

2025 · Backend & Database Architecture

Student Marks Management System

Layered Backend Architecture & Relational Schemas

🔒 High Data Integrity Enterprise Backend

A robust academic records management engine engineered with FastAPI and SQL relational databases, enforcing strict Pydantic schema validation, ACID transaction guarantees, and sub-3ms query indexing.

1 / 3

What it does

  • Designed a clean layered backend architecture cleanly separating presentation, service business logic, and data access layers.
  • Implemented RESTful API endpoints with FastAPI for academic records, grade transcripts, GPA calculations, and department management.
  • Enforced strict Pydantic schema validation across all incoming payloads to eliminate invalid grades, malformed student IDs, and SQL injection risks.
  • Constructed a normalized relational database schema with foreign key cascade policies, unique constraints, and atomic multi-table transactions.
  • Achieved sub-3ms query execution times through compound B-tree indexing on frequent query paths (student USN + semester + course code).
  • Built a comprehensive automated API testing suite using Pytest and HTTPX with 100% pass rate on edge boundary conditions.

Built with

Python · FastAPI · PostgreSQL / SQLite · SQLAlchemy · Pydantic · Pytest · REST APIs
